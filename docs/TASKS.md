# CM_assets_3030 Task Board

## 제품 성격

CM_assets_3030은 전표 입력/발주 승인 ERP가 아니라, 경영계획 예산 편성·제출·검토·확정·실적 비교·초과 점검을 지원하는 예산관리 서브 시스템이다.

직접 처리하지 않는 범위:
- 전표 입력
- 발주 승인
- 계약 승인
- 실제 지출 결재
- 회계 ERP 원장 대체

핵심 범위:
- 경영계획 예산 입력
- 예산 제출 / 검토 / 확정
- 확정 후 잠금
- 계획/실적 업로드
- 예산 초과 점검
- 계정별 / 부서별 분석
- 조직변경에 따른 예산 이관 보조
- 백업/복구
- 감사 로그

## P0 - 즉시 수정

### 1. 1원 sentinel / 0원 오염 흔적 제거
- [ ] `!== 1`, `amount !== 1`, `val !== 1` 전수 검색
- [ ] 1원을 임시값처럼 제외하는 로직 제거
- [ ] 0원은 유효한 예산값으로 유지
- [ ] 미입력은 row 없음 또는 null로 명확히 구분
- [ ] 예산 작성 / 계획 업로드 / 비교분석 / 초과점검 영향 확인

승인 기준:
- 0원 예산이 0원으로 저장/표시된다.
- 1원 예산도 실제 값으로 저장/표시된다.
- 집계에서 1원이 임의 제외되지 않는다.

## P1 - 예산 입력 그리드 개선

현재 문제:
- 계정과목명이 길어 숫자 입력란이 좁아진다.
- 빈칸이 많아 실제 입력해야 할 셀을 찾기 어렵다.
- 계정명/산출근거/월별 숫자가 한 화면에서 충돌한다.
- 전체 가로 스크롤에서 사용자가 현재 어느 계정/월을 보고 있는지 놓치기 쉽다.

개선 태스크:
- [ ] 계정코드 / 계정명 / 산출근거 컬럼 sticky 처리
- [ ] 계정명 컬럼 기본 폭 축소 + tooltip 전체명 표시
- [ ] 계정명 2줄 clamp 처리
- [ ] 숫자 입력칸 최소 폭 확보
- [ ] 월별 입력 셀 compact mode 추가
- [ ] 빈 row 숨기기 토글 추가
- [ ] 0원 셀 흐리게 표시하되 값은 변경하지 않음
- [ ] 입력된 셀만 강조 표시
- [ ] 계정별 접기/펼치기
- [ ] 제조/판관 그룹 접기/펼치기
- [ ] 월별 합계 row sticky bottom 또는 상단 요약 추가
- [ ] Tab / Enter / 방향키 이동 UX 점검
- [ ] 붙여넣기 후 변경된 셀 highlight
- [ ] “입력 필요 계정만 보기” 필터 추가
- [ ] “금액 있는 계정만 보기” 필터 추가
- [ ] 계정명 클릭 시 상세 패널에서 전체 계정명, 산출근거, 전년실적 표시

권장 UI 방향:
- 계정명은 표 안에서 길게 보여주지 말고, 짧게 줄이고 tooltip/상세패널로 보완한다.
- 숫자 입력 영역을 최우선으로 넓힌다.
- 0원은 유효값이므로 절대 1원 등으로 바꾸지 않는다.
- 빈칸이 많은 문제는 숨기기/필터/강조로 해결한다.

승인 기준:
- 12개월 숫자 입력란이 현재보다 넓고 안정적으로 보인다.
- 계정명이 길어도 월별 입력칸이 과도하게 줄지 않는다.
- 0원 데이터가 오염되지 않는다.
