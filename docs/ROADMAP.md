# CM_assets_3030 Roadmap

## 제품 방향

CM_assets_3030은 메인 ERP를 대체하지 않는다.

이 시스템은 경영계획 예산 편성, 실적 업로드, 예산 초과 점검, 계정별/부서별 분석, 조직변경에 따른 예산 이관을 지원하는 예산관리 서브 시스템이다.

직접 하지 않는 것:
- 전표 입력
- 발주 승인
- 계약 승인
- 회계 원장 관리
- 실제 지출 결재

집중할 것:
- 경영계획 예산 입력
- 예산 제출/검토/확정
- 확정 후 잠금
- 실적 업로드
- 예산 대비 실적 점검
- 초과/무예산 집행 탐지
- 분석 보고서 다운로드
- 조직변경에 따른 예산 재배치
- 감사로그
- 백업/복구

## Phase 0. 데이터 보존성과 숫자 신뢰도 확보

목표:
localStorage 기반 로컬 앱의 가장 큰 리스크를 제거한다.

작업:
- 전체 백업/복구
- 1원 sentinel 제거
- 제출상태 통일
- REVIEWING / LOCKED 잠금 처리
- Excel 합계 오류 수정
- 실적 업로드의 예산 직접 이동 제거
- 감사로그 기반 추가
- placeholder 집계 함수 제거

완료 기준:
- 백업/복구 가능
- 제출률 정상 표시
- 잠금 상태 우회 수정 불가
- 비교분석 다운로드 합계 일치
- 실적 수정이 예산 데이터를 직접 이동하지 않음

## Phase 1. 예산 입력 UX와 작성 효율 개선

목표:
부서 담당자가 경영계획 예산을 빠르고 정확하게 입력할 수 있게 한다.

작업:
- 예산 입력 그리드 개선
- 계정명 길이로 인한 숫자 입력칸 축소 해결
- sticky columns
- compact numeric grid
- 빈 row 숨기기
- 입력된 셀 강조
- 계정 상세 패널
- 전년도 실적/예산 자동 불러오기
- 증감률 일괄 적용
- 붙여넣기 UX 개선

완료 기준:
- 숫자 입력칸 가독성 개선
- 빈칸이 많은 화면에서도 입력 대상이 명확함
- 전년도 기준 예산 초안 생성 가능

## 예산 입력 그리드 개선 방향

현재 문제:
- 계정과목명이 길어 월별 숫자 입력칸이 좁다.
- 빈칸이 많아 입력해야 할 셀이 잘 보이지 않는다.
- 계정명, 산출근거, 월별 입력값이 같은 표 안에서 충돌한다.

개선 방향:
1. 계정명 컬럼 폭을 줄이고 tooltip/상세패널로 전체 계정명 표시
2. 계정코드, 계정명, 산출근거 sticky column 처리
3. 월별 숫자 입력칸 최소 폭 보장
4. 0원은 흐리게 표시하되 값은 변경하지 않음
5. 입력값이 있는 셀만 강조
6. 빈 row 숨기기
7. 금액 있는 계정만 보기
8. 입력 필요 계정만 보기
9. 제조/판관 그룹 접기/펼치기
10. 계정 클릭 시 우측 상세 패널 표시
11. 산출근거는 표 안에서 길게 보여주지 않고 패널에서 관리
12. 붙여넣기 후 변경 셀 highlight
13. 키보드 이동 UX 강화
14. 전체 합계 / 분기 합계 sticky summary 제공

금지:
- 0원을 1원으로 바꾸는 방식
- 긴 계정명을 위해 숫자 입력칸을 희생하는 방식
- 입력 셀이 너무 좁아져 숫자가 잘리는 방식

## Phase 2. 경영계획 제출/검토/확정 플로우

목표:
예산 담당자가 부서별 경영계획 제출 상태를 관리할 수 있게 한다.

상태:
- DRAFT
- SUBMITTED
- REVIEWING
- REJECTED
- APPROVED
- LOCKED

작업:
- 제출
- 검토중 전환
- 반려 사유 기록
- 재제출
- 확정
- 확정 후 잠금
- 제출률 대시보드
- 상태별 필터
- 감사로그 기록

주의:
이 플로우는 전표 승인이나 지출 승인 기능이 아니다.
경영계획 예산안에 대한 제출/검토/확정 기능이다.

완료 기준:
- 부서별 경영계획 상태 확인 가능
- 확정된 예산은 우회 수정 불가
- 반려 사유와 변경 이력이 남음

## Phase 3. 분석 탭 완성

목표:
예산 담당자가 부서별/계정별로 예산 집행 상태를 볼 수 있게 한다.

작업:
- 계정별 현황
- 부서별 현황
- 예산 초과 점검 고도화
- 무예산 집행 점검
- 비교분석 개선
- Excel 다운로드 표준화
- 권한별 다운로드 필터 보장

완료 기준:
- 전사 → 부서 → 계정 → 월 상세 드릴다운 가능
- 급여 권한 없는 사용자는 인건비 계정 조회 불가
- 화면과 다운로드 결과가 일치

## Phase 4. 조직변경과 예산 이관

목표:
조직변경이 잦아도 예산 비교와 귀속이 깨지지 않게 한다.

작업:
- 조직버전 관리
- 조직변경 전/후 비교
- 1:N 부서 분할
- N:1 부서 통합
- N:N 매핑
- 계정별/월별 이관금액 직접 입력
- 이관 전/후 합계 검증
- 이관 확정
- 원본 데이터 보존
- 이관 반영 조직 기준 조회

완료 기준:
- 한 부서가 두 부서로 나뉘어도 계정별/월별 금액 이관 가능
- 이관 전/후 차액 검증 가능
- 기존 예산 데이터는 보존됨

## Phase 5. 로컬 우선 인프라 고도화

목표:
로컬 사용성을 유지하면서 웹 전환 가능한 구조를 만든다.

작업:
- BudgetRepository 도입
- BackupRepository 도입
- PermissionService/usePermission 통일
- AuditLogService
- localStorage → SQLite 전환 준비
- 향후 API 저장소 교체 가능 구조
- `.env`, `.xlsx`, `.json backup`, `.sqlite` gitignore 강화

완료 기준:
- 페이지가 localStorage를 직접 호출하는 비율 감소
- 저장소 교체 시 페이지 수정 최소화

## Phase 6. 선택형 고급 기능

장기 검토:
- 월별 집행 추세 예측
- What-if 시나리오
- 경보 임계값 알림
- 계정별 전년 동기 비교
- 모바일 간이 조회
- ERP 실적 파일 자동 import

주의:
사전 집행 승인, 커밋먼트, 전표 승인, 발주 승인은 메인 ERP 영역이므로 기본 범위에 넣지 않는다.
필요 시 외부 ERP 연계 조회 항목으로만 검토한다.
